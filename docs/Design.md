# Design System & UI Specification - Nexora

## 1. Color Palette & Theme
- **Theme:** Modern Dark/Light Hybrid (Dark dominant for AI Buyer Chat, Slate/Clean Light for Merchant Dashboard).
- **Primary Accent:** Cyber Violet / Indigo (`#6366F1`) - Represents AI capabilities.
- **Secondary Accent:** Electric Emerald (`#10B981`) - Signals successful transactions, approvals, and stock availability.
- **Background Dark:** Slate 950 (`#020617`)
- **Card Background:** Slate 900 (`#0F172A`) with Subtle Border Slate 800 (`#1E293B`).
- **Text Primary:** Slate 50 (`#F8FAFC`) | **Text Secondary:** Slate 400 (`#94A3B8`).

## 2. Typography
- **Primary Sans Font:** `Inter`, system-ui, sans-serif.
- **Monospace Font:** `JetBrains Mono` or `Fira Code` (Used for technical product specs, JSON structures, and agent timeline logs).

## 3. UI Component Patterns
- **Agent Chat Bubble:** Distinct borders with animated glowing primary accent during active Groq tool-calling.
- **Product Recommendation Card:** Compact horizontal layout featuring key spec highlights, price match score, and a clear "Approve & Buy" action CTA.
- **Merchant Metric Badge:** High-contrast pill badges indicating conversion efficiency and stock status.
